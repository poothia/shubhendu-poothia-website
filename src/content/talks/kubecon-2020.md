Selected as a speaker for KubeCon 2020 in Amsterdam to present a POC on low-latency location-based service routing — a critical capability for 5G network functions running on Kubernetes.

The talk explored how cloud-native routing can reduce latency for geographically distributed services, a key requirement for next-generation telecom infrastructure.
